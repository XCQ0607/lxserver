权限与缓存限制

针对公开用户与普通登录用户的权限管控

开启公开用户限制 开启后，未验证的公开用户将被限制核心缓存设置与公开音源查看管理
开启非管理员访问本地音乐 允许未登录管理员的公开账号访问本地音乐
开启非管理员浏览器下载 允许未登录管理员的公开账号使用浏览器下载歌曲
开启非管理员服务器缓存 允许未登录管理员的公开账号将歌曲缓存或写入服务器存储
开启公开收藏和歌曲 开启后允许登陆管理员的情况下对公开用户创建公开收藏与本地音乐歌单文件（说明：只有登录管理员后才可以管理收藏歌单和本地歌单）
开启非管理员访问 允许未登录管理员的公开账号查看公开收藏和歌曲
开启登录用户缓存限制 开启后，所有非管理员登录用户将被限制核心缓存设置（不影响音源管理）
开启缓存空间限制 开启后，当缓存总量超出限制时将按时间顺序（LRU）自动清理最旧文件
允许 VM 模式运行脚本 允许某些需要原生 VM 模式运行以突破沙盒限制的自定义音源脚本（如部分混淆脚本）。警告：原生 VM 模式不具备沙盒安全性，可能导致服务器被执行任意系统命令，请仅在信任脚本来源时开启。

Subsonic 协议配置

启用后支持第三方 Subsonic 客户端（如 PlaySub, Symfonium）

启用 Subsonic 服务 允许 Subsonic 客户端连接并同步歌单
Subsonic 调试日志模式 开启后将在服务器控制台中实时打印所有客户端发起的 Subsonic 请求与缺失接口提示
Subsonic API 默认路径为 /rest。修改后需在客户端同步更新 URL
开启全网在线搜索 允许 Subsonic 客户端在搜索歌曲时检索全网音乐 API
可选 wy,tx,kw,kg,mg，用英文逗号分隔
开启歌词翻译支持 允许在 Subsonic 歌词响应中包含翻译文本（原文在上，翻译在下）
💡 Subsonic 客户端搜索：直接输入歌曲名时使用上方“默认在线搜索模式”。也可在搜索框中使用以下前缀：
• all:歌名 / online:歌名：搜索全部已启用在线平台
• local:歌名：只搜索本地歌单
• wy:歌名、tx:歌名、kw:歌名、kg:歌名、mg:歌名：指定网易、QQ、酷我、酷狗或咪咕
客户端支持音乐目录时，也可选择“全部在线平台”或单个平台目录后再搜索。同时间戳歌词顺序为原文在上，翻译在下。
设置歌手详情、头像及简介的获取来源优先级
配置修改后需要保存方可生效，部分配置需重启服务器
