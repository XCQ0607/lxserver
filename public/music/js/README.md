# 播放器脚本目录

| 目录 | 职责 |
| --- | --- |
| core/ | 本地存储与 PWA |
| download/ | 下载管理与同步下载 |
| library/ | 歌单、搜索、榜单、歌曲操作与黑名单 |
| local/ | 本地音乐、自定义目录、识别匹配与文件状态 |
| lyrics/ | 歌词解析、工具与歌词卡片 |
| player/ | 播放、音质、音效、可视化与投屏 |
| player/pitch-shifter/ | AudioWorklet 变调模块 |
| sync/ | 用户数据同步 |
| ui/ | 通用界面、分页、主题与无障碍 |
| vendor/ | 第三方脚本，保留原始文件名和授权信息 |

脚本仍由 `../index.html` 按原先顺序加载，共享全局接口保持不变。
资源地址相对于播放器页面；AudioWorklet 的模块引用相对于模块本身。
移动或新增脚本时同步检查页面引用、动态加载、`../sw.js` 缓存清单及根目录的 Tailwind 扫描配置。
