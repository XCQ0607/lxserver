# 同步服务与管理控制台指南

LX Music Sync Server 包含一个专业的 Web 管理控制台（默认位于路径 `/admin`，即 `http://IP:9527/admin`），用于查看服务运行状态、管理用户账号与多设备连接、审查歌单与快照、以及配置服务端功能。

## 登录与鉴权

访问管理控制台（默认 `http://IP:9527/admin`）需要输入管理员密码。

- **默认密码**：`123456`
- **修改密码**：您可以通过设置环境变量 `ADMIN_PASSWORD` 覆盖默认密码，或在登录后前往后台“系统配置”页面修改。修改后会持久化保存在服务端的 `data/config.js` 文件中。

## 🔗 客户端同步与连接配置

服务端为各端客户端提供了灵活的连接接入方式：

### 1. LX Music 客户端同步（桌面端 / 移动端）
进入客户端「设置 → 同步设置」，选择自定义连接：
- **用户路径模式（推荐，默认开启 `USER_ENABLE_PATH=true`）**：
  - **连接 URL**：`http://<服务器IP>:9527/<用户名>`（例如 `http://192.168.1.100:9527/user1`）
  - **连接密码**：对应用户的密码
  - **机制说明**：服务端通过 URL 路径中的用户名将请求精确路由至对应用户的独立数据沙盒。**此模式下允许多个不同用户使用相同的同步密码**。
- **根路径模式（需在系统配置中开启 `USER_ENABLE_ROOT=true`）**：
  - **连接 URL**：`http://<服务器IP>:9527`（无需携带用户名）
  - **连接密码**：对应用户的密码
  - **机制说明**：连接 URL 即为根路径，服务端通过客户端在握手阶段传递的密码自动反查匹配对应用户。**注意：此模式下所有用户的密码必须保持全局唯一，不允许不同用户使用相同密码**。

### 2. Subsonic 音乐客户端连接（音流 / Feishin / Symfonium 等）
全面适配 Subsonic / OpenSubsonic 协议：
- **服务器地址 (Server URL)**：
  - **默认共享主端口**：`http://<服务器IP>:9527/rest`（子路径由 `SUBSONIC_PATH` 控制，默认 `/rest`）
  - **独立端口监听**（若设置了 `SUBSONIC_PORT` > 0，例如 `4533`）：`http://<服务器IP>:4533/rest`
- **用户名 & 密码**：在管理后台“用户管理”中创建的用户名及对应密码。
- **在线全网搜索**：支持在客户端搜索框中直接搜索并串流各平台歌曲，可加前缀（如 `wy:`、`tx:`、`kw:`、`kg:`、`mg:`）指定音源平台，或使用 `online:` / `local:` 强制切换在线/本地搜索。

## 功能模块说明

### 1. 仪表盘 (Dashboard)

显示当前服务的运行状态与基础统计信息：

- **基础指标**：显示当前 WebSocket 连接的设备数量、Node.js 进程占用的内存 (RAM) 以及服务启动后的连续运行时间 (Uptime)。
- **用户统计**：显示系统中已创建的用户总数。
- **运行日志**：前端实时展示控制台日志输出，方便查看请求历史与报错信息。

### 2. 用户与设备管理 (Access & Devices)

用于管理多账户以及查看当前连接的客户端设备。

- **多账号分离**：可以创建多个用户账号，各个账号对应的歌单数据和设置在服务端独立存放，互不影响。
- **设备管理**：可以查看当前正在连接服务的客户端设备与 IP 来源，并支持强制断开指定的设备连结。
- **删除用户与清理数据**：在删除用户账号时，可以选择同时清除该用户对应在服务器上的所有历史歌单数据和缓存文件。

### 3. 数据查看 (Data Tracker & Viewer)

用于在网页端直接查阅用户的同步数据。

- **歌单明细查看**：可以浏览服务端所保存的所有分类音乐列表、歌曲信息与收藏记录。
- **快照与回滚**：系统会在同步发生变更时自动保存歌单数据的历史快照（Snapshot）。当客户端发生误清理或异常覆盖时，可以在这里下载以前的完整数据，或者直接针对服务端进行一键回滚还原。

### 4. WebDAV 备份与同步 (WebDAV Backup)

用于将服务端数据定期打包传输到第三方 WebDAV 存储。

- **定期备份**：配置并启用 WebDAV 账号后，服务端会开启定时任务（默认每 60 分钟），将当前的所有用户记录打包上传至指定网盘。
- **自动拉取恢复**：当在一台全新空数据的服务器上初次启动时，若检测到填有 WebDAV 环境变量，服务端会先行从网盘下载最新备份文件并覆盖到本地，借此完成旧数据的导入和恢复。

### 5. 系统设置与维护

可以在网页执行常规的文件清理操作：

- **缓存清理**：点击相关按钮即可命令服务端直接删除旧的媒体缓存文件或日志记录，从而释放磁盘空间。
- **导出日志**：可打包下载服务端近期产生的运行异常日志，用于差错分析。
