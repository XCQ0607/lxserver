# Subsonic 本地音乐库

Subsonic 客户端可访问当前账号的服务器音乐文件、缓存及自定义音乐目录。本页说明目录范围、歌单配置、媒体读取和持久化数据；接口范围见 [Subsonic 协议支持](../api/subsonic.md)。

## 接入与目录范围

1. 在后台为账号选择持久化存储位置；使用 NAS 目录时，启用该账号的自定义音乐目录并保证服务进程可读取。
2. 在后台“Subsonic 协议配置”中启用需要的本地歌单入口并保存。
3. 在客户端选择“NAS 本地音乐（存储目录＋自定义目录）”音乐文件夹，浏览本地专辑、艺术家、流派和歌曲。目录浏览模式也提供 NAS 入口。
4. 添加或更新文件后，可通过客户端的扫描功能调用 `startScan` 刷新索引。

| 账号存储设置 | 内置曲库范围 |
| --- | --- |
| `data` | 数据目录下该账号的 `music`、`cache` |
| `root` | 程序根目录下该账号的 `music`、`cache` |
| 已启用的自定义目录 | 在内置曲库之外收录该目录的可访问文件；相同实际文件只收录一次 |

网页文件管理器中的临时目录切换不改变 Subsonic 的曲库范围。切换账号存储位置或关闭自定义目录后，后续请求使用新的目录范围；已保存的歌曲 ID 不能绕过访问范围限制。

## 本地歌单配置

后台“Subsonic 协议配置 → 本地歌曲歌单”提供以下设置：

| 配置项 | 默认值 | 行为 |
| --- | --- | --- |
| `subsonic.localPlaylist` | `true` | 返回只读的“本地歌曲(用户名)”歌单；关闭后不返回该歌单及自定义目录歌单 |
| `subsonic.customPlaylist` | `true` | 父开关开启且账号已启用自定义目录时，单独返回“自定义目录(用户名)”歌单 |
| `subsonic.cachePlaylist` | `false` | 是否在“本地歌曲”歌单中合并当前存储位置的 `cache` 歌曲；关闭时仅显示 `music` 歌曲 |

本地歌单在服务端返回列表中排在前面，客户端自行排序时以客户端规则为准。已启用的入口即使没有歌曲也会保留。关闭父开关会保留子开关的设置。

自定义目录歌曲与内置目录歌曲分开展示。自定义目录指向内置 `music` 或 `cache` 时，文件优先归属内置目录，不重复加入自定义目录歌单；其中的缓存歌曲仍受缓存目录开关控制。这些开关只控制歌单展示，不缩减搜索、专辑和评分等接口共用的完整曲库。

## 浏览、搜索与扫描

- 指定 NAS 本地音乐文件夹时，专辑等浏览接口使用本地曲库。默认推荐页的“最新专辑”“随机专辑”仍使用在线推荐池，不自动混入 NAS 专辑。
- `local:关键词` 只搜索本地文件；普通搜索按服务器搜索设置处理，显式在线搜索使用在线分支。
- 索引读取曲序、碟号、专辑艺术家、年份和流派。专辑按所在目录、专辑名及专辑艺术家分组，避免不同目录中的版本混合。
- 目录范围不变时，曲库结果缓存 30 秒；`startScan` 可主动刷新。`getScanStatus` 返回扫描状态、歌曲数量及失败原因。

## 播放、封面与歌词

本地歌曲支持详情、播放、下载及 HTTP Range 请求。歌曲和专辑时长按协议返回整数秒，内部保留精确时长；文件大小返回实际字节数。

服务端开启转码并安装可用的 ffmpeg 后，本地播放可进行格式转换、码率限制和时间偏移。相关配置与限制见 [协议支持说明](../api/subsonic.md#转码与媒体限制)。

### 歌词来源

按以下顺序查找可用歌词：

1. 非空的同名外置 LRC 文件。
2. 音频文件的内嵌歌词。
3. 网页播放器的服务器歌词缓存。
4. 已关联音乐平台的在线歌词接口。

在线回退只使用已关联的平台 ID，不按歌名猜测其他歌曲。请求有超时限制，并按账号复用并发请求、短暂缓存成功结果。结构化歌词接口可返回原文、翻译和音译；普通歌词接口按翻译配置合并。支持多时间标签、整数秒标签和 offset，不额外转换为 OpenSubsonic 逐字歌词格式。

### 封面来源

本地歌曲读取音频内嵌或目录封面，并兼容客户端附加的 `al-`、`ar-`、`tr-`、`sg-`、`mg-` 前缀；读取范围仍受当前账号权限约束。

普通用户歌单的列表与详情返回统一封面令牌。解析时优先使用歌单网络封面；关联网络歌单缺少封面时尝试向原平台获取，再回退到第一首歌曲的封面，包括本地封面。空歌单没有可用封面时返回空内容。解析按账号隔离。

## 文件身份与关联

每个本地文件使用独立的 `local_<UUID>`。关联在线平台不会改变 ID，也不会改写音频标签。响应通过 `lxStorage=local`、`lxLinked` 和 `comment` 表达本地身份与关联状态，是否显示由客户端决定。

本地歌曲不会按歌名与在线歌曲自动合并。身份登记按实际路径保存：在原路径更新文件或关联平台会保留 ID；外部移动、重命名文件会被视为新文件，不进行指纹追踪。不在当前目录范围内的歌曲会停止显示，但原歌单引用和收藏仍保留，切回原目录后可恢复。

## 收藏与歌单同步

| 操作 | 存储及同步行为 |
| --- | --- |
| 创建纯本地歌单 | 只保存在服务器，不进入 LX 官方客户端同步 |
| 创建混合歌单 | 在线歌曲写入原生歌单，本地成员及混排顺序独立保存 |
| 在线歌单重新同步 | 在线成员随同步增删，本地成员保留；新增在线成员默认追加到合成列表末尾 |
| 按位置删除歌曲 | 按客户端看到的混合列表解析位置 |
| 删除混合歌单 | 删除原生在线歌单与本地附加信息，不删除音频文件 |
| 收藏本地歌曲 | 使用 `star` / `unstar`；向内置“我的喜爱”歌单直接添加本地成员会返回提示 |

原生歌单被其他同步操作删除后，本地附加成员仍可作为服务端歌单查看。播放记录、队列和书签可解析本地歌曲。

## 数据备份与排查

以下文件位于用户目录，应随用户数据一起备份：

| 文件 | 内容 |
| --- | --- |
| `subsonic-local-registry.json` | 文件身份和元数据；不是可随意清理的缓存 |
| `subsonic-local-state.json` | 本地收藏、纯本地歌单及混合歌单附加信息 |

曲库缺失时，先核对账号存储位置、自定义目录开关和服务进程的文件权限，再发起扫描并查看 `getScanStatus`。本地歌单缺少缓存歌曲时，检查 `subsonic.cachePlaylist`。

部分客户端会根据歌曲 `size` 决定是否加载歌单封面。在线歌曲优先返回音源提供的字节数，缺失时按码率和时长估算；未知时长且没有已知大小时仍返回 0。估算值不用于实际音频响应的 Content-Length 或 Range。

大曲库扫描速度取决于目录访问和标签读取性能；转码取决于 ffmpeg 与服务端资源。封面、歌词、扫描进度及其他控件的展示也受客户端实现影响。
