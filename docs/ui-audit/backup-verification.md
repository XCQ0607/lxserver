# 备份设置与恢复验证

本次改动位于 `review/pr-488-openlist`，包含 PR #488 的数据安全修复及统一备份范围。没有提交或推送。

## 界面决定

- 系统设置首先回答“哪些数据会备份到哪个云端”，用五行数据类型和 WebDAV/OpenList 两列勾选展示。
- 使用 Framed sheet 方向，seed `1449062923`，保留既有管理台字体、主题和页面框架；新范围面板使用平面分隔，不新增图标卡片或统计数字。
- 普通数据备份与永久播放缓存分开。普通数据备份没有“上传后删本地”的选项；恢复单独执行。
- 保留本地副本、镜像删除、启动恢复的后果写在控制旁；不把未保存的选择用于恢复。

- `npm test`：50 项通过，其中 OpenList/播放交付 20 项，TypeScript 测试 30 项。
- TypeScript `--noEmit`、前端及配置 JS 语法、`git diff --check` 通过。

- 使用生产配置读取字段和实际 `saveConfigToFile` 写入函数，验证类型数组、布尔设置及 Subsonic 交付设置保存、重新加载后的往返一致性；写入失败会报告错误并清理临时文件。
